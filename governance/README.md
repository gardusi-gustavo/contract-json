# Governance

Account-wide inventory, policy, bundle order, rulesets, App manifest, and
archive history.

- `repos.json` — master inventory of 41 repositories
- `policy.json` — merge, PR, label, and agent policy
- `orgs.json` — organization metadata
- `bundle-order.json` — topological backup and restore order
- `backup-policy.json` — backup retention and destinations
- `archive-migration.json` — retired and migrated repository history
- `rulesets/` — GitHub branch and tag rulesets
- `app-manifest.json` — GitHub App manifest
